Suimworks("회사")는 HS Finder 앱("서비스") 이용자의 개인정보를 소중히 여기며,
「개인정보 보호법」 및 관련 법령을 준수합니다.

## 1. 수집하는 개인정보 항목

### 1.1 수집 항목

| 항목 | 수집 방법 | 목적 |
|------|-----------|------|
| Google 계정 이름, 이메일 | Google 로그인 | 본인 확인 및 계정 관리 |
| 서비스 이용 기록 (분석 횟수, 크레딧) | 서비스 이용 시 자동 수집 | 크레딧 관리 및 무료 제공 횟수 추적 |
| 결제 정보 | RevenueCat (Google Play / App Store) | 인앱 결제 처리 |

### 1.2 수집하지 않는 항목

- 상품 이미지는 분석 후 서버에 영구 저장되지 않습니다.
- 위치 정보는 수집하지 않습니다.
- 연락처, 주소 등의 민감 정보는 수집하지 않습니다.

## 2. 개인정보 수집 및 이용 목적

- **서비스 제공**: Google 로그인 기반 계정 인증 및 사용자 식별
- **기능 제공**: HS 코드 AI 분류 기능 (이미지 분석, Cloud Function 호출)
- **크레딧 관리**: 무료 이용 횟수 추적, 인앱 결제 후 크레딧 지급
- **서비스 개선**: 오류 로그 및 사용 통계 (개인 식별 불가 형태)

## 3. 개인정보 보유 및 이용 기간

| 항목 | 보유 기간 |
|------|-----------|
| 계정 정보 (이름, 이메일) | 회원 탈퇴 시 즉시 삭제 |
| 서비스 이용 기록 | 회원 탈퇴 시 즉시 삭제 |
| 결제 기록 | 「전자상거래 등에서의 소비자 보호에 관한 법률」에 따라 5년 |

## 4. 개인정보의 제3자 제공

회사는 이용자의 동의 없이 개인정보를 제3자에게 제공하지 않습니다.
단, 서비스 운영에 필요한 수탁 업체에 최소한의 정보를 위탁합니다.

| 수탁자 | 위탁 목적 | 보유 기간 |
|--------|-----------|-----------|
| Google Firebase | 계정 인증, 데이터 저장 | 회원 탈퇴 시 삭제 |
| OpenAI | HS 코드 AI 분류 (이미지·텍스트 처리) | 요청 처리 후 즉시 삭제 |
| RevenueCat | 인앱 결제 처리 | 결제 관련 법령 보존 기간 |

## 5. 이용자의 권리

이용자는 언제든지 아래 권리를 행사할 수 있습니다.

- **열람**: 수집된 개인정보 확인 요청
- **수정**: 부정확한 개인정보 정정 요청
- **삭제**: 개인정보 삭제 및 계정 탈퇴 요청 (앱 내 계정 삭제 기능 제공)
- **처리 정지**: 개인정보 처리 정지 요청

계정 삭제는 앱 내 **설정 → 계정 삭제** 메뉴를 통해 직접 진행할 수 있습니다.

## 6. 개인정보 보호를 위한 기술적·관리적 조치

- Firebase Security Rules를 통한 데이터 접근 제어
- HTTPS 암호화 통신
- 최소 권한 원칙에 따른 Firebase 서비스 계정 관리
- OpenAI API 키 서버 사이드 관리 (클라이언트 미노출)

## 7. 쿠키 및 추적 기술

이 앱은 쿠키를 사용하지 않습니다.
Firebase Analytics를 통해 익명화된 사용 통계를 수집할 수 있으며, 이는 개인 식별이 불가능한 형태입니다.
